formulon-cell is a browser spreadsheet UI kit aiming for Excel compatibility, with vanilla TypeScript, React, and Vue entrypoints.

Setup instructions and examples live in the [documentation](https://formulon.libraz.net/cell/).

## Install

```sh
npm install @libraz/formulon-cell zustand
```
