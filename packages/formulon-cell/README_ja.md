formulon-cell は、Excel 互換を目指すブラウザ向けの表計算 UI キットです。Vanilla TypeScript、React、Vue から組み込めます。

導入手順と利用例は [ドキュメント](https://formulon.libraz.net/ja/cell/) にまとめています。

## インストール

```sh
npm install @libraz/formulon-cell zustand
```
